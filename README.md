# RANDOM_STAR

Минимальная iOS-демка интерактивного 3D-куба на SwiftUI и SceneKit.

- Куб следует за свайпом по горизонтали и вертикали.
- После отпускания учитывается скорость жеста.
- Медленный жест возвращает куб к фронтальной стороне.
- Быстрый горизонтальный жест запускает полный оборот с пружинным затуханием.
- Внешние библиотеки, модели, изображения и частицы не используются.

## Запуск

1. Откройте `RANDOM_STAR.xcodeproj` в Xcode 16 или новее.
2. Выберите iPhone Simulator.
3. Нажмите Run.

Для запуска на физическом устройстве выберите собственную команду разработчика в Signing & Capabilities.
